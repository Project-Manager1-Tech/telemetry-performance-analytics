# Telemetry Performance Analytics Dashboard

## Overview

End-to-end analytics project built using Python, PostgreSQL, SQL, and Power BI to monitor IoT device fleet performance and operational risk.

## Dataset

100,000 telemetry records
500 devices
Multiple deployment locations

## Tech Stack

- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Power BI

## Analytics Features

- Device health scoring
- Risk event detection
- Error severity analysis
- Network latency monitoring
- Throughput analysis
- Fleet performance monitoring

## Dashboard Pages

### Executive Overview

KPIs and fleet-level metrics.

### Device Health Analysis

Error-prone and low-health devices.

### Performance Monitoring

CPU, memory, latency and throughput analytics.

### Risk Monitoring

High-risk devices and risk trends.

## Key Outcomes

- Built analytics pipeline for 100K+ records.
- Designed business KPIs and operational metrics.
- Created interactive multi-page Power BI dashboard.
